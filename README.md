# 群聊截图_选择性隐藏_拼接出图
[界面.png](https://github.com/RayCheung9527/Chat-screenshot-overlay-splicing/blob/77aae6441a601380ae7cea28d09fd30fdce2746d/%E7%95%8C%E9%9D%A2.png)


## 一、软件简介

“群聊截图_选择性隐藏_拼接出图”是一款基于 Python Tkinter 的桌面长图拼接工具。它用于将多张群聊截图按顺序拼接为一张长图，并可在每张截图上添加遮罩，选择性地隐藏不想展示的区域。最终保存时，被遮罩覆盖的区域会被裁剪掉，未遮罩区域按顺序垂直拼接输出。

## 二、主要用途

- 拼接多张群聊截图成长图。
- 对截图中的头像、昵称、时间、消息、敏感内容等区域添加遮罩，选择性隐藏。
- 在预览中调整遮罩位置和高度，确认后导出最终长图。
- 支持不同宽度图片，统一以最大宽度为画布，较窄图片居中。

## 三、运行环境与依赖

- Python 3
- 标准库：tkinter、os
- 图像处理：Pillow（PIL）
  - 安装：`pip install Pillow`
- 可选拖拽支持：tkinterdnd2
  - 安装：`pip install tkinterdnd2`
  - 未安装时软件仍可使用，但无法通过拖拽文件导入，只能通过“+ 添加图片”选择文件。
- 启动：运行包含 `ProMerger` 类的 Python 脚本，或执行 `python 文件名.py`。

## 四、界面布局

窗口默认大小约 1200x800，分为顶部工具栏、左侧图片列表区、右侧预览画布区。

### 1. 顶部工具栏

从左到右包含：

- `+ 添加图片`：打开文件选择对话框，批量添加图片。
- `🗑 删除选中图片`：删除左侧当前选中的图片及其遮罩。
- `本图遮罩清空`：清除当前选中图片上的所有遮罩。
- `删除选中遮罩`：删除右侧当前选中的遮罩。
- `+ 添加遮罩`：在当前选中图片上添加一个默认遮罩。
- `生成并保存`：按当前顺序和遮罩设置拼接图片，并保存为 PNG 或 JPEG。

### 2. 左侧图片列表

- 以缩略图形式显示已添加图片，缩略图最大约 180x300。
- 每张图下方显示文件名。
- 当前选中图片使用较粗边框高亮。
- 支持点击选中图片。
- 支持按住缩略图拖拽调整图片顺序。
- 支持鼠标滚轮滚动列表。
- 删除图片后，相关遮罩索引会自动调整，并自动选择相邻图片。

### 3. 右侧预览画布

- 显示按当前顺序垂直排列的拼接预览。
- 带有垂直滚动条和水平滚动条。
- 鼠标滚轮可垂直滚动预览。
- 按住 Ctrl 并滚动鼠标滚轮可缩放预览。
- 在画布空白处按住鼠标拖动，可平移预览视图。
- 点击画布空白处会取消遮罩选中状态。
- 窗口大小变化时自动刷新预览。

## 五、核心功能

### 1. 图片导入

- 通过“+ 添加图片”按钮打开文件选择框，可一次选择多张图片。
- 如果已安装 tkinterdnd2，可直接将图片文件拖拽到软件窗口导入。
- 支持格式：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.webp`。
- 导入后自动生成缩略图并加入左侧列表。
- 若首次导入且未选中图片，会自动选中第一张图片。
- 无法打开某张图片时，会弹出错误提示。

### 2. 图片选择

- 在左侧列表中点击任意图片缩略图或文件名即可选中。
- 选中后，右侧画布会刷新，并可在该图片上添加或编辑遮罩。
- 选中状态在左侧以边框高亮显示。

### 3. 图片删除

- 选中图片后，点击“🗑 删除选中图片”可删除该图片。
- 删除图片时，该图片上的遮罩会一并删除。
- 其他图片上的遮罩索引会自动修正，保证遮罩仍对应正确图片。
- 删除后若仍有图片，会自动选中相邻图片。

### 4. 图片排序

- 在左侧列表中按住某张图片缩略图拖动到其他位置，可调整图片顺序。
- 调整顺序后，右侧预览和最终拼接顺序同步更新。
- 遮罩会跟随原图片移动，不会错位到其他图片。

### 5. 添加遮罩

- 先在左侧选中要处理的图片。
- 点击“+ 添加遮罩”。
- 若未选择图片，会提示“请先选择图片”。
- 新遮罩默认位于图片高度约 43.75% 处，高度约为图片高度的 12.5%。
- 遮罩以灰色半透明网格显示在右侧预览画布上。
- 遮罩表示最终输出时将被裁剪或隐藏的区域。

### 6. 遮罩选中与编辑

- 点击右侧画布中的遮罩可选中它。
- 选中后的遮罩边缘显示红色线框。
- 鼠标悬停在遮罩不同位置时，光标会变化：
  - 上边缘、下边缘：显示上下调整光标。
  - 遮罩内部：显示移动光标。
- 拖动遮罩内部：整体上下移动遮罩。
- 拖动遮罩上边缘：调整遮罩顶部位置和高度。
- 拖动遮罩下边缘：调整遮罩底部位置和高度。
- 遮罩位置和高度以相对图片高度的比例保存，预览缩放不会影响最终裁剪结果。
- 遮罩不能超出图片范围，高度最小为图片高度的 2%。

### 7. 删除遮罩

- 选中遮罩后，点击“删除选中遮罩”可删除该遮罩。
- 也可以按键盘 `Delete` 或 `Backspace` 删除当前选中遮罩。
- 若未选中遮罩，会提示先在右侧画布中点击选中一个遮罩。

### 8. 清空当前图片遮罩

- 选中某张图片后，点击“本图遮罩清空”。
- 只清除该图片上的所有遮罩，不影响其他图片。
- 清空后当前遮罩选中状态取消。

### 9. 预览缩放与滚动

- 初次打开或添加图片后，预览会按画布宽度自动计算缩放比例。
- 鼠标滚轮：在右侧画布上垂直滚动。
- `Ctrl + 鼠标滚轮`：缩放预览。
- 预览缩放仅影响显示效果，不影响原图分辨率和保存结果。
- 支持水平滚动条，用于查看较宽图片。

### 10. 生成并保存

- 点击“生成并保存”。
- 若没有图片，会提示“没有图片可合并”。
- 弹出保存对话框，可选择保存为 PNG 或 JPEG，默认扩展名为 `.png`。
- 保存时按左侧图片顺序从上到下拼接。
- 每张图片中，被遮罩覆盖的垂直区域会被裁剪掉。
- 未被遮罩覆盖的区域会保留并依次拼接。
- 多遮罩重叠时，会合并处理覆盖区域，避免重复裁剪或错位。
- 最终输出宽度取所有图片中的最大宽度。
- 较窄图片会水平居中放置在白色背景上。
- 保存成功后提示保存路径。
- 保存失败时弹出错误提示。

## 六、保存与拼接规则

1. 图片顺序：以左侧列表当前顺序为准。
2. 输出宽度：所有图片中的最大宽度。
3. 输出高度：每张图片裁剪掉遮罩区域后的高度总和。
4. 遮罩处理：遮罩按垂直位置排序，重叠部分自动合并。
5. 裁剪范围：遮罩覆盖的纵向区域被移除，未覆盖区域保留。
6. 对齐方式：宽度不足最大宽度的图片水平居中。
7. 背景颜色：白色。
8. 输出格式：PNG 或 JPEG。

## 七、典型操作流程

1. 启动软件。
2. 点击“+ 添加图片”选择群聊截图，或直接拖拽图片到窗口。
3. 在左侧列表中点击选择要处理的图片。
4. 点击“+ 添加遮罩”，在右侧预览中调整遮罩位置和高度，覆盖需要隐藏的内容。
5. 如有需要，继续添加多个遮罩，或删除、清空遮罩。
6. 在左侧拖拽调整图片顺序。
7. 点击“生成并保存”，选择保存路径和格式。
8. 得到选择性隐藏后的拼接长图。

## 八、快捷键

- `Delete`：删除当前选中的遮罩。
- `Backspace`：删除当前选中的遮罩。
- `Ctrl + 鼠标滚轮`：在右侧预览画布中缩放。
- 鼠标滚轮：在左侧列表或右侧画布中滚动。
- 鼠标拖动：在右侧画布空白处平移视图；在遮罩上移动或调整边缘。

## 九、提示与异常

- 未选择图片时添加遮罩：提示“请先选择图片”。
- 未选中遮罩时删除遮罩：提示先在右侧画布中点击选中遮罩。
- 没有图片时生成：提示“没有图片可合并”。
- 图片无法打开：弹出错误提示并显示文件名和原因。
- 保存失败：弹出保存失败提示并显示错误信息。
- 未安装 tkinterdnd2：软件仍可运行，但无法拖拽导入文件。

## 十、注意事项

- 遮罩只是预览中的灰色标记，最终保存时对应区域会被裁剪掉，而不是变成灰色。
- 遮罩使用相对比例记录位置，因此预览缩放、窗口大小变化不会影响最终裁剪位置。
- 删除图片或调整图片顺序时，遮罩会自动跟随或调整索引。
- 若多张图片宽度不同，输出长图以最大宽度为准，较窄图片居中。
- 建议在保存前通过右侧预览确认遮罩位置和图片顺序。
- 保存为 JPEG 时，透明背景会以白色背景输出。
